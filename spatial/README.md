# SpatialTag

Inspect and inject spherical video and spatial audio metadata in MP4/MOV files.

SpatialTag CLI command: `spatialtag`

**Full guide:**
[nandan-18.github.io/spatialtag/docs/cli.html](https://nandan-18.github.io/spatialtag/docs/cli.html)

```bash
python3 -m pip install -e .
spatialtag -h
```

Pre-built binaries: [GitHub
Releases](https://github.com/Nandan-18/spatialtag/releases/latest)

# Spatial Audio Resources

HRIR reference WAV files for ambisonic binaural monitoring in a DAW.

**Full guide:** [nandan-18.github.io/spatial-media/guide/audio.html](https://nandan-18.github.io/spatial-media/guide/audio.html)

Download `audio.zip` from [GitHub Releases](https://github.com/Nandan-18/spatial-media/releases/latest) or use the files in this directory after cloning the repository.
